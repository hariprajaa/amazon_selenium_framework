# Amazon Automation Task

## Project Description

This project automates the Amazon shopping journey using Selenium WebDriver, Java, Maven, and TestNG following the Page Object Model (POM) design pattern.

## Features Automated

- User Login
- Product Search
- Brand Filter
- Product Selection
- Add Product to Cart
- Update Cart Quantity
- Proceed to Checkout
- Select UPI Payment
- Continue to Payment Page

## Tech Stack

- Java
- Selenium WebDriver
- Maven
- TestNG
- Page Object Model (POM)

2. Open the project in VS Code or Eclipse.

```bash
mvn test
```
